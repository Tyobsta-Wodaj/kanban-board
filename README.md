# Kanban Board

A task management web application that helps users organize and track tasks across different stages of a workflow.

## Features

- Create and manage tasks
- Organize tasks by status
- Move tasks between columns
- Simple and responsive interface
- User-friendly task management

## Technologies

HTML · CSS · JavaScript
